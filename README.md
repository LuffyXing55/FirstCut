# 初剪 FirstCut

像改作文一样剪视频。

导入口播视频，字幕自己出来。在文稿里划掉说错的话、去掉「嗯」「呃」，视频就跟着剪好了。识别和 AI 都在你的 Mac 上运行，免费，不登录，不加水印。

## 下载

**[下载最新版 FirstCut-mac.zip](https://github.com/luffyxing55/FirstCut/releases/latest/download/FirstCut-mac.zip)**

历次版本和更新说明在 [Releases](https://github.com/luffyxing55/FirstCut/releases)。

需要：

- M1 及更新芯片的 Mac（暂时不支持 Intel 芯片）
- macOS 14 Sonoma 或更高版本
- 建议 16 GB 内存，8 GB 也能用

## 第一次打开

内测版还没有经过苹果公证，所以 macOS 第一次会拦一下，允许一次就好：

1. 双击下载好的 zip，把解压出来的 `FirstCut` 拖到「应用程序」文件夹。
2. 双击打开，系统提示无法验证开发者，点「完成」（不要点「移到废纸篓」）。
3. 打开「系统设置 → 隐私与安全性」，拉到最下面，点「仍要打开」，输入开机密码。
4. 以后直接双击就能打开。第一次打开会列出要下载的识别模型和 AI 助手，勾好点开始下载，下载时可以先剪别的。

## 能做什么

- **文稿式剪辑**：说的每句话都在一张稿纸上，删字就是剪视频，剪错了按 ⌘Z
- **一键去语气词和停顿**：嗯、呃、口头禅、长停顿、说错重说的那一遍
- **高精度字幕**：本地 Whisper 识别，没把握的字标黄；支持有稿对齐和个人词库
- **AI 帮你剪**（本地千问模型）：说一句话剪视频、找重点词、写发布文案、长视频切短视频
- **六套口播模板**：墨白、荧光笔、胶片日记、克莱因、夜光、国潮，字幕、话题条、片头片尾、封面一次配齐
- **导出**：MP4（720p 到 4K），也可以只导出 SRT 字幕、TXT 文稿、M4A 声音或 JPG 封面
